    tasks.removeIf(task -> task.getName().equalsIgnoreCase(name));

## [Issue #3] List tasks sorted by name

- git checkout -b 3-list-tasks-sorted-by-name
- Имплементирано:

```java
public List<Task> listTasksSortedByName() {
    return tasks.stream()
                .sorted(Comparator.comparing(Task::getName))
                .collect(Collectors.toList());
}
```

- git add SI2025Lab1Main.java
- git commit -m "Implement listTasksSortedByName"
- git push origin 3-list-tasks-sorted-by-name

## [Issue #5] Filter tasks by category

- git checkout -b 5-filter-tasks-by-category
- Имплементирано:

```java
public List<Task> filterByCategory(String category) {
    return tasks.stream()
                .filter(task -> task.getCategory().equalsIgnoreCase(category))
                .collect(Collectors.toList());
}
```

- git add SI2025Lab1Main.java
- git commit -m "Implement filterByCategory"
- git push origin 5-filter-tasks-by-category
